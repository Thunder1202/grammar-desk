Zero conditional

General info

The zero conditional talks about things that are always true — facts, rules and habits. We use if + present simple, present simple.

  • If you heat water to 100°C, it boils.
  • If I drink coffee late, I can't sleep.
  • Plants die if they don't get water.

We use it for

  • Facts and science: If you mix red and blue, you get purple.
  • Rules and instructions: If the red light is on, don't enter.
  • Personal habits: If I get home late, I eat little.
Both parts are in the present simple. You can often use when instead of if with the same meaning: When you heat water, it boils.

Нулевой условный говорит о том, что всегда верно — о фактах, правилах и привычках. Используем if + present simple, present simple.

  • If you heat water to 100°C, it boils.
  • If I drink coffee late, I can't sleep.
  • Plants die if they don't get water.

Когда используем

  • Факты и наука: If you mix red and blue, you get purple.
  • Правила и инструкции: If the red light is on, don't enter.
  • Личные привычки: If I get home late, I eat little.
Обе части в present simple. Часто можно использовать when вместо if с тем же значением: When you heat water, it boils.

Nolinchi shart mayli har doim to'g'ri bo'lgan narsalar — faktlar, qoidalar va odatlar haqida gapiradi. if + present simple, present simple ishlatamiz.

  • If you heat water to 100°C, it boils.
  • If I drink coffee late, I can't sleep.
  • Plants die if they don't get water.

Nima uchun ishlatamiz

  • Faktlar va fan: If you mix red and blue, you get purple.
  • Qoidalar va ko'rsatmalar: If the red light is on, don't enter.
  • Shaxsiy odatlar: If I get home late, I eat little.
Ikkala qism ham present simple da. Ko'pincha if o'rniga when ishlatsa bo'ladi, ma'no bir xil: When you heat water, it boils.

Teacher's rule

If-clauseMain clause
If + present simplepresent simple
If you heat ice,it melts.
If it rains,the streets get wet.
If I don't sleep,I feel tired.
  1. Form: If + present simple, present simple.
  2. You can change the order: It boils if you heat it. (no comma when if is in the middle)
  3. Meaning: a general truth — the result is always the same.
  4. if and when are often both possible here.
  5. Do not use will in the zero conditional: If you heat water, it boils (not "will boil").
  6. Compare: zero conditional = always true; first conditional = one real future possibility.

Why present in both parts?

The zero conditional is about things that are always true, not one moment in time. Present Simple is the tense for facts and habits, so we use it in both parts.

if or when? And instructions

when = it is sure to happen; if = it may or may not happen: When I wake up, I drink water. (every day) If I wake up at night, I drink water. (only sometimes)

For instructions and advice, the result can be an imperative: If you feel sick, stay at home. If the light is red, don't cross.

Zero or first conditional?

Zero (always true)First (one future situation)
If it rains, the roads get wet.If it rains tomorrow, we will stay at home.
If I drink coffee late, I can't sleep.If I drink this coffee now, I won't sleep tonight.
  1. Форма: If + present simple, present simple.
  2. Порядок можно менять: It boils if you heat it. (без запятой, когда if в середине)
  3. Значение: общая истина — результат всегда одинаковый.
  4. if и when здесь часто взаимозаменяемы.
  5. Не используем will в нулевом условном: If you heat water, it boils (не «will boil»).
  6. Сравни: нулевой условный = всегда верно; первый условный = одна реальная будущая возможность.

Почему настоящее время в обеих частях?

Нулевое условное говорит о том, что верно всегда, а не об одном моменте. Present Simple — время для фактов и привычек, поэтому оно стоит в обеих частях.

if или when? И инструкции

when = это точно случится; if = может случиться, а может и нет: When I wake up, I drink water. (каждый день) If I wake up at night, I drink water. (только иногда)

В инструкциях и советах результат может быть повелительным: If you feel sick, stay at home. If the light is red, don't cross.

Zero или First Conditional?

Zero (всегда верно)First (одна ситуация в будущем)
If it rains, the roads get wet.If it rains tomorrow, we will stay at home.
If I drink coffee late, I can't sleep.If I drink this coffee now, I won't sleep tonight.
  1. Shakl: If + present simple, present simple.
  2. Tartibni o'zgartirsa bo'ladi: It boils if you heat it. (if o'rtada bo'lsa, vergul yo'q)
  3. Ma'no: umumiy haqiqat — natija har doim bir xil.
  4. Bu yerda if va when ko'pincha ikkalasi ham bo'ladi.
  5. Nolinchi shart maylida will ishlatilmaydi: If you heat water, it boils ("will boil" emas).
  6. Taqqoslang: nolinchi = har doim to'g'ri; birinchi shart = bitta real kelajak imkoni.

Nega ikkala qismda ham hozirgi zamon?

Zero conditional bir lahza haqida emas, doim to'g'ri bo'lgan narsalar haqida. Present Simple — faktlar va odatlar zamoni, shuning uchun ikkala qismda ham u ishlatiladi.

Ko'rsatma va maslahatlarda natija buyruq bo'lishi mumkin: If you feel sick, stay at home. If the light is red, don't cross.

Student explanation

Ask yourself two questions

  1. Is it always true, every time? Yes → zero conditional.
  2. Both parts present simple? They should be.

Common mistakes

  • If you heat water, it will boils. If you heat water, it boils.
  • If you will heat water, it boils. If you heat water, it boils.
  • If I am tired, I went to bed. If I am tired, I go to bed.
  • When water freezes, it became ice. When water freezes, it becomes ice.
If the meaning is "every time, always", keep both verbs (action words) in the present.

In plain words

This is for things that always happen, like a machine. If you press the button, the same thing happens every time. There is no maybe.

  • If you heat ice, it melts. This is always true.
  • If you press this button, the door opens. It works the same every time.
  • If I drink coffee late, I can't sleep. This happens to me every time.

Use the same simple form in both parts. You can also say when instead of if.

Задай себе два вопроса

  1. Это верно всегда, каждый раз? Да → нулевой условный.
  2. Обе части в present simple? Так и должно быть.

Частые ошибки

  • If you heat water, it will boils. If you heat water, it boils.
  • If you will heat water, it boils. If you heat water, it boils.
  • If I am tired, I went to bed. If I am tired, I go to bed.
  • When water freezes, it became ice. When water freezes, it becomes ice.
Если смысл «каждый раз, всегда», держи оба глагола (это слово-действие) в настоящем времени.

Простыми словами

Это для того, что происходит всегда, как у машины. Нажмёте кнопку — и каждый раз будет одно и то же. Никаких «может быть».

  • If you heat ice, it melts. Если нагреть лёд, он тает. Это верно всегда.
  • If you press this button, the door opens. Если нажать эту кнопку, дверь открывается. Каждый раз одинаково.
  • If I drink coffee late, I can't sleep. Если я пью кофе поздно, я не могу уснуть. Так каждый раз.

В обеих частях одна и та же простая форма. Вместо if можно сказать when.

O'zingizga ikkita savol bering

  1. Bu har doim, har safar to'g'rimi? Ha → nolinchi shart mayli.
  2. Ikkala qism present simple da mi? Shunday bo'lishi kerak.

Ko'p uchraydigan xatolar

  • If you heat water, it will boils. If you heat water, it boils.
  • If you will heat water, it boils. If you heat water, it boils.
  • If I am tired, I went to bed. If I am tired, I go to bed.
  • When water freezes, it became ice. When water freezes, it becomes ice.
Agar ma'no «har safar, har doim» bo'lsa, ikkala fe'lni (harakat so'zi) ham hozirgi zamonda saqlang.

Oddiy so'zlar bilan

Bu har doim bo'ladigan narsalar uchun, xuddi mashinadek. Tugmani bossangiz, har safar bir xil narsa bo'ladi. "Balki" yo'q.

  • If you heat ice, it melts. Muzni qizdirsangiz, u eriydi. Bu doim to'g'ri.
  • If you press this button, the door opens. Bu tugmani bossangiz, eshik ochiladi. Har safar bir xil.
  • If I drink coffee late, I can't sleep. Kech qahva ichsam, uxlay olmayman. Har safar shunday.

Ikkala qismda bir xil oddiy shakl. If o'rniga when ham deyish mumkin.

Real-life use

You use the zero conditional for facts, rules and your habits.

Science class

"If you cool water below zero, it freezes."

Instructions

"If the alarm rings, leave the building quickly."

Habits

"If I don't eat breakfast, I feel hungry all morning."

Health advice

"If you exercise every day, you feel better."

IELTS Speaking: daily routine

"If I have free time, I usually read or go for a walk."

Examples and drill

Science

If you heat ice, it melts. Water boils if you heat it to 100°C.

Rules

If the light is red, don't cross. If you press this button, the door opens.

Habits

If I drink coffee late, I can't sleep. I feel tired if I don't sleep well.

Always true

Plants die if they don't get water. If you mix red and blue, you get purple.

Drill

1. If you ___ (heat) ice, it melts.
heat
2. Water ___ (freeze) if the temperature is below 0.
freezes
3. If I ___ (not / sleep) enough, I feel tired.
don't sleep
4. When it ___ (rain), the streets get wet.
rains
5. If you press this button, the machine ___ (start).
starts
6. If children ___ (not / eat), they get hungry.
don't eat
7. Correct it: If you heat water, it will boils.
If you heat water, it boils.
8. Correct it: When I am hungry, I ate.
When I am hungry, I eat.

Make it negative

9. If you water plants, they grow. (make both parts negative)
If you don't water plants, they don't grow.
10. If I eat breakfast, I feel hungry later. (make the if-part negative)
If I don't eat breakfast, I feel hungry later.

Make a question

11. (what / happen / if / you / heat / ice)?
What happens if you heat ice?
12. (what / you / do / if / you / miss / the bus)?
What do you do if you miss the bus?

Give an instruction

13. If you ___ (have) a question, ___ (raise) your hand.
have, raise
14. If the baby ___ (sleep), ___ (not / make) a noise.
is sleeping / sleeps, don't make

if or when?

15. ___ I get home from work, I always have a shower. (every day)
When
16. ___ my phone breaks, I use my sister's. (it may happen)
If

Zero or first?

17. If you ___ (drop) glass, it ___ (break).
drop, breaks (zero: always true)
18. If you ___ (drop) that glass, I ___ (be) angry!
drop, will be (first: one real situation)
19. If it ___ (snow) tomorrow, the school ___ (close).
snows, will close (first)

Find the mistake

20. If you don't sleep, you will feel always tired.
If you don't sleep, you always feel tired.
21. What happen if you press this?
What happens if you press this?
