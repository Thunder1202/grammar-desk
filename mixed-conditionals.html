Mixed conditionals

General info

Mixed conditionals combine two types. The if-part and the result belong to different times: a past action with a present result, or a present state with a past result.

We use them for

  • Past cause, present result: If I had studied medicine, I would be a doctor now.
  • Present or permanent state, past result: If I weren't so shy, I would have asked her out.
  • Life changes and regrets: If I hadn't met you, I wouldn't be here today.

Words that go with them

now, today, still, these days, yesterday, last year, then.

Check the time of each part separately. Do not copy the form of the first part into the second.

Смешанные условные соединяют два типа. Условие и результат относятся к разному времени: прошлое действие с результатом сейчас или состояние сейчас с результатом в прошлом.

Когда используем

  • Причина в прошлом, результат сейчас: If I had studied medicine, I would be a doctor now.
  • Состояние сейчас или постоянное, результат в прошлом: If I weren't so shy, I would have asked her out.
  • Перемены в жизни и сожаления: If I hadn't met you, I wouldn't be here today.

Слова-подсказки

Qachon ishlatamiz

  • O'tmishdagi sabab, hozirgi natija: If I had studied medicine, I would be a doctor now.
  • Hozirgi yoki doimiy holat, o'tmishdagi natija: If I weren't so shy, I would have asked her out.
  • Hayotdagi o'zgarishlar va afsuslar: If I hadn't met you, I wouldn't be here today.

Teacher's rule

Mixif-clauseresult clause
past → presentIf I had taken that job,I would be rich now.
present → pastIf I weren't afraid of flying,I would have gone to Japan.
PatternForm
past → presentIf + past perfect, would + base verb
present → pastIf + past simple, would have + participle
  1. Mixed = the if-part and the result belong to different times.
  2. Past → present: if + past perfect, would + base verb. A past action has a present result: If I had saved money, I would have a car now.
  3. Present → past: if + past simple, would have + participle. A present or permanent state had a past result: If I were taller, I would have joined the team.
  4. Check each part separately: now, today, still → would + verb. yesterday, last year, then → would have + participle.
  5. Could and might can replace would. Never put would in the if-clause: If I had known (not: if I would have known).
  6. Negative and question: If I hadn't met her, I wouldn't be here. What would your life be like if you had stayed?
  1. Смешанные = условие и результат относятся к разному времени.
  2. Прошлое → настоящее: if + past perfect, would + основная форма. Прошлое действие даёт результат сейчас: If I had saved money, I would have a car now.
  3. Настоящее → прошлое: if + past simple, would have + третья форма. Состояние сейчас или постоянное дало результат в прошлом: If I were taller, I would have joined the team.
  4. Проверяй каждую часть отдельно: now, today, still → would + глагол. yesterday, last year, then → would have + третья форма.
  5. Could и might могут заменять would. Would в if-части никогда: If I had known (не: if I would have known).
  6. Отрицание и вопрос: If I hadn't met her, I wouldn't be here. What would your life be like if you had stayed?
  1. Aralash = shart va natija turli vaqtga tegishli.
  2. O'tmish → hozir: if + past perfect, would + asosiy shakl. O'tmishdagi ish hozirgi natija beradi: If I had saved money, I would have a car now.
  3. Hozir → o'tmish: if + past simple, would have + uchinchi shakl. Hozirgi yoki doimiy holat o'tmishda natija bergan: If I were taller, I would have joined the team.
  4. Har bir qismni alohida tekshiring: now, today, still → would + fe'l. yesterday, last year, then → would have + uchinchi shakl.
  5. Could va might would o'rnida kelishi mumkin. if qismida hech qachon would yo'q: If I had known (if I would have known emas).
  6. Inkor va so'roq: If I hadn't met her, I wouldn't be here. What would your life be like if you had stayed?

Student explanation

Ask yourself three questions

  1. When is the condition? A finished past action → had + participle. A present state → past simple.
  2. When is the result? Now → would + verb. In the past → would have + participle.
  3. Do the two times match? Yes → Second or Third Conditional. No → mixed.

Example

Fact: I didn't study medicine, so I am not a doctor now. → If I had studied medicine, I would be a doctor now.

Common mistakes

  • If I had studied medicine, I would have been a doctor now. If I had studied medicine, I would be a doctor now.
  • If I would be taller, I would have joined the team. If I were taller, I would have joined the team.
  • If I would have saved money, I would have a car now. If I had saved money, I would have a car now.
  • If I weren't shy, I would ask her yesterday. If I weren't shy, I would have asked her yesterday.
Do not copy the first part's form into the second. Ask "when?" twice.

Задай себе три вопроса

  1. Когда условие? Законченное действие в прошлом → had + третья форма. Состояние сейчас → past simple.
  2. Когда результат? Сейчас → would + глагол. В прошлом → would have + третья форма.
  3. Время совпадает? Да → Second или Third Conditional. Нет → смешанное.

Пример

Факт: I didn't study medicine, so I am not a doctor now. → If I had studied medicine, I would be a doctor now.

Частые ошибки

  • If I had studied medicine, I would have been a doctor now. If I had studied medicine, I would be a doctor now.
  • If I would be taller, I would have joined the team. If I were taller, I would have joined the team.
  • If I would have saved money, I would have a car now. If I had saved money, I would have a car now.
  • If I weren't shy, I would ask her yesterday. If I weren't shy, I would have asked her yesterday.

O'zingizga uchta savol bering

  1. Shart qachon? O'tmishdagi tugagan ish → had + uchinchi shakl. Hozirgi holat → past simple.
  2. Natija qachon? Hozir → would + fe'l. O'tmishda → would have + uchinchi shakl.
  3. Ikkala vaqt mos keladimi? Ha → Second yoki Third Conditional. Yo'q → aralash.

Real-life use

We use mixed conditionals to reflect on life, personality and how the past still affects us.

Reflecting on a decision

"If I had gone to university abroad, I'd have a different job now."

Explaining character

"If I weren't so shy, I would have asked her out."

Life changes

"If I hadn't met you, I wouldn't be here today."

IELTS Speaking: a turning point

"If I hadn't started learning English, I wouldn't be able to study abroad now."

Examples and drill

Past → present

If I had taken that job, I would be rich now. If she had listened, she wouldn't be in trouble today.

Present → past

If I weren't afraid of flying, I would have gone to Japan. If he were more careful, he wouldn't have broken it.

Question

What would your life be like if you had stayed in your hometown?

Drill

1. If I ___ (study) medicine, I would be a doctor now.
had studied
2. If she ___ (not be) so shy, she would have joined the club.
weren't
3. If we had left earlier, we ___ (be) at the airport now.
would be
4. If I were rich, I ___ (buy) that house last year.
would have bought
5. Choose: If I (had saved / saved) money, I would have a car now.
had saved
6. Which mix? If I had taken the job, I would be rich now. (past → present / present → past)
past → present
7. Correct it: If I had studied medicine, I would have been a doctor now.
If I had studied medicine, I would be a doctor now.
