So and such

General info

So and such make an adjective or a situation stronger. They often show a result.

  • so + adjective / adverb: The film was so boring.
  • such + (adjective) + noun: It was such a boring film.
  • so ... that: It was so cold that the lake froze.
  • such ... that: It was such a cold day that the lake froze.
Rule of thumb: so before an adjective alone; such before a noun (with or without an adjective). "so a nice day" is wrong; "such a nice day" is right.

So и such усиливают прилагательное или ситуацию. Часто они показывают результат.

  • so + прилагательное / наречие: The film was so boring.
  • such + (прилагательное) + существительное: It was such a boring film.
  • so ... that: It was so cold that the lake froze.
  • such ... that: It was such a cold day that the lake froze.
Основное правило: so перед одним прилагательным; such перед существительным (с прилагательным или без). «so a nice day» неверно; «such a nice day» верно.

So va such sifat yoki holatni kuchaytiradi. Ko'pincha natija ni ko'rsatadi.

  • so + sifat / ravish: The film was so boring.
  • such + (sifat) + ot: It was such a boring film.
  • so ... that: It was so cold that the lake froze.
  • such ... that: It was such a cold day that the lake froze.
Asosiy qoida: so yakka sifatdan oldin; such otdan oldin (sifat bilan yoki sifatsiz). "so a nice day" xato; "such a nice day" to'g'ri.

  1. so + adjective / adverb: She is so kind. He ran so fast.
  2. so much / so many / so little / so few + noun: so many cars, so little money.
  3. such + a/an + adjective + singular noun: such a nice day.
  4. such + adjective + plural or uncountable noun: such nice people, such bad weather.
  5. so ... that and such ... that show a result: It was so hot that we stayed inside.
  6. Never use so directly before a singular noun: use "such a".

Exclamations and questions

In speech, so and such often show strong feeling, with no that-clause: You're so kind! It's such a beautiful day! In questions: Why are you so angry? Why was there such a long queue?

  1. so + прилагательное / наречие: She is so kind. He ran so fast.
  2. so much / so many / so little / so few + существительное: so many cars, so little money.
  3. such + a/an + прилагательное + существительное в ед. ч.: such a nice day.
  4. such + прилагательное + существительное во мн. ч. или неисчисляемое: such nice people, such bad weather.
  5. so ... that и such ... that показывают результат: It was so hot that we stayed inside.
  6. Никогда не ставь so прямо перед существительным в ед. ч.: используй «such a».

Восклицания и вопросы

В речи so и such часто показывают сильное чувство, без части с that: You're so kind! It's such a beautiful day! В вопросах: Why are you so angry? Why was there such a long queue?

  1. so + sifat / ravish: She is so kind. He ran so fast.
  2. so much / so many / so little / so few + ot: so many cars, so little money.
  3. such + a/an + sifat + birlikdagi ot: such a nice day.
  4. such + sifat + ko'plik yoki sanalmaydigan ot: such nice people, such bad weather.
  5. so ... that va such ... that natijani ko'rsatadi: It was so hot that we stayed inside.
  6. Hech qachon so ni to'g'ridan-to'g'ri birlikdagi otdan oldin ishlatmang: "such a" ishlatiladi.

Student explanation

Ask yourself one question

Is there a noun (word for a person, thing or idea) right after the word? Yes → use such (+ a/an). No, only an adjective/adverb → use so.

Common mistakes

  • It was so a nice day. It was such a nice day.
  • He is such tall. He is so tall.
  • She has so a big house. She has such a big house.
  • There were such many people. There were so many people.
Noun after the gap → such (a). Only adjective/adverb after the gap → so.

In plain words

Both words make something stronger, and can show a result. The only question is what comes next. So goes with a describing word alone. Such goes with a whole thing.

  • The test was so hard. So + describing word.
  • It was such a hard test. Such + a + describing word + thing.
  • It was so cold that we stayed at home. Add that to show the result.

Quick test: is there a thing after it (film, day, people)? Use such. If not, use so.

Задай себе один вопрос

Есть ли сразу после слова существительное (это слово-предмет)? Да → используй such (+ a/an). Нет, только прилагательное/наречие → используй so.

Частые ошибки

  • It was so a nice day. It was such a nice day.
  • He is such tall. He is so tall.
  • She has so a big house. She has such a big house.
  • There were such many people. There were so many people.
Существительное после пропуска → such (a). Только прилагательное/наречие → so.

Простыми словами

Оба слова усиливают и могут показывать результат. Вопрос только в том, что идёт дальше. So идёт с одним словом-описанием. Such идёт с целым предметом.

  • The test was so hard. Тест был таким трудным. So + слово-описание.
  • It was such a hard test. Это был такой трудный тест. Such + a + описание + предмет.
  • It was so cold that we stayed at home. Было так холодно, что мы остались дома. That показывает результат.

Быстрая проверка: дальше есть предмет (film, day, people)? Ставьте such. Если нет, so.

O'zingizga bitta savol bering

So'zdan keyin darhol ot (odam yoki narsa nomi) keladimi? Ha → such (+ a/an). Yo'q, faqat sifat/ravish → so.

Ko'p uchraydigan xatolar

  • It was so a nice day. It was such a nice day.
  • He is such tall. He is so tall.
  • She has so a big house. She has such a big house.
  • There were such many people. There were so many people.
Bo'shliqdan keyin ot → such (a). Faqat sifat/ravish → so.

Oddiy so'zlar bilan

Ikkala so'z ham kuchaytiradi va natijani ko'rsatishi mumkin. Savol faqat keyin nima kelishida. So yolg'iz tasvirlovchi so'z bilan, such esa butun narsa bilan keladi.

  • The test was so hard. Test juda qiyin edi. So + tasvirlovchi so'z.
  • It was such a hard test. Bu juda qiyin test edi. Such + a + tasvirlovchi + narsa.
  • It was so cold that we stayed at home. Shunchalik sovuq ediki, uyda qoldik. That natijani ko'rsatadi.

Tez tekshiruv: keyin narsa bormi (film, day, people)? Such qo'ying. Bo'lmasa, so.

Real-life use

So and such add strong feeling to what you say — surprise, pleasure or complaint.

Describing a place

"It was such a beautiful beach that we stayed all day."

Describing feelings

"I was so tired that I fell asleep on the sofa."

Complaining

"There was so much traffic that we missed the train."

Complimenting

"She's such a kind person."

IELTS Speaking: a memorable trip

"The mountains were so high, and the weather was such a surprise that we took hundreds of photos."
