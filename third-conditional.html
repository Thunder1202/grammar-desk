Third Conditional

General info

The Third Conditional talks about an imaginary situation in the past that did not happen, and its imaginary result. We use it for regrets and for saying what could have been different.

We use it for

  • Imaginary past situations: If I had studied, I would have passed. (I didn't study. I failed.)
  • Regrets: If I had left earlier, I wouldn't have missed the train.
  • Criticism and hindsight: If you had told me, I would have helped.

Words that go with it

if, had + participle, would have, wouldn't have, could have, might have.

Russian: если бы я учился, я бы сдал. Uzbek: agar o'qiganimda edi, o'tgan bo'lardim. English marks it with had + participle and would have + participle.

Third Conditional говорит о воображаемой ситуации в прошлом, которой не было, и её воображаемом результате. Мы используем его для сожалений и для рассказа о том, что могло быть иначе.

Когда используем

  • Воображаемые ситуации в прошлом: If I had studied, I would have passed. (Я не учился. Я не сдал.)
  • Сожаления: If I had left earlier, I wouldn't have missed the train.
  • Упрёк и взгляд назад: If you had told me, I would have helped.

Слова-подсказки

if, had + третья форма, would have, wouldn't have, could have, might have.

Русский: если бы я учился, я бы сдал. Узбекский: agar o'qiganimda edi, o'tgan bo'lardim. В английском had + третья форма и would have + третья форма.

Third Conditional o'tmishdagi bo'lmagan xayoliy holat va uning xayoliy natijasi haqida gapiradi. Uni afsuslanish va nima boshqacha bo'lishi mumkin edi deyish uchun ishlatamiz.

Qachon ishlatamiz

  • O'tmishdagi xayoliy holatlar: If I had studied, I would have passed. (O'qimadim. O'ta olmadim.)
  • Afsuslanish: If I had left earlier, I wouldn't have missed the train.
  • Tanqid va keyingi xulosa: If you had told me, I would have helped.

Yordamchi so'zlar

if, had + uchinchi shakl, would have, wouldn't have, could have, might have.

Rus tili: если бы я учился, я бы сдал. O'zbek tili: agar o'qiganimda edi, o'tgan bo'lardim. Inglizchada had + uchinchi shakl va would have + uchinchi shakl.

Teacher's rule

if-clauseresult clause
+If I had studied,I would have passed.
−If I hadn't missed the bus,I wouldn't have been late.
?What would you have done if you had lost your phone?
could / mightIf she had tried,she might have passed.
  1. Form: If + past perfect, would have + past participle. Short forms: I'd have, hadn't, wouldn't have.
  2. Use: an imaginary past situation that is the opposite of what really happened, and its imaginary result: If I had left earlier, I wouldn't have missed the train. (I didn't leave early. I missed it.)
  3. No would have in the if-clause: If I had known (not: if I would have known).
  4. could have / might have instead of would have: If she had tried, she might have passed.
  5. Order and comma: if-clause first → comma. Result first → no comma: I would have helped if you had asked.
  6. Second or Third? Imaginary present or future → Second: If I had money, I would buy it. Imaginary past → Third: If I had had money, I would have bought it.
  1. Форма: If + past perfect, would have + третья форма. Краткие формы: I'd have, hadn't, wouldn't have.
  2. Употребление: воображаемая ситуация в прошлом, обратная реальной, и её воображаемый результат: If I had left earlier, I wouldn't have missed the train. (Я не вышел рано. Я опоздал на поезд.)
  3. Нет would have в if-части: If I had known (не: if I would have known).
  4. could have / might have вместо would have: If she had tried, she might have passed.
  5. Порядок и запятая: if-часть первой → запятая. Результат первым → без запятой: I would have helped if you had asked.
  6. Second или Third? Воображаемое настоящее или будущее → Second: If I had money, I would buy it. Воображаемое прошлое → Third: If I had had money, I would have bought it.
  1. Shakl: If + past perfect, would have + uchinchi shakl. Qisqa shakllar: I'd have, hadn't, wouldn't have.
  2. Qo'llanishi: haqiqatga teskari o'tmishdagi xayoliy holat va uning xayoliy natijasi: If I had left earlier, I wouldn't have missed the train. (Erta chiqmadim. Poyezdga kechikdim.)
  3. if qismida would have yo'q: If I had known (if I would have known emas).
  4. could have / might have would have o'rnida: If she had tried, she might have passed.
  5. Tartib va vergul: if qismi birinchi → vergul. Natija birinchi → vergulsiz: I would have helped if you had asked.
  6. Second yoki Third? Xayoliy hozir yoki kelajak → Second: If I had money, I would buy it. Xayoliy o'tmish → Third: If I had had money, I would have bought it.

Student explanation

Ask yourself three questions

  1. Is it about the past, and did it not happen? Yes → Third Conditional.
  2. Which part has the condition? The if-part → had + participle. The result → would have + participle.
  3. Is it a regret or criticism? Often yes: If I had listened ... / If you had told me ...

Fact and imagination

Fact: I didn't study, so I failed. / Imagination: If I had studied, I wouldn't have failed.

Common mistakes

  • If I would have known, I would have helped. If I had known, I would have helped.
  • If I had studied, I would passed. If I had studied, I would have passed.
  • If I knew about the party, I would have come. If I had known about the party, I would have come.
  • If she had tried, she would has passed. If she had tried, she would have passed.
Two had-forms never go together: not "if I would have". After if use had, after the comma use would have.

Задай себе три вопроса

  1. Это про прошлое, и этого не произошло? Да → Third Conditional.
  2. В какой части условие? В if-части → had + третья форма. Результат → would have + третья форма.
  3. Это сожаление или упрёк? Часто да: If I had listened ... / If you had told me ...

Факт и воображение

Факт: I didn't study, so I failed. / Воображение: If I had studied, I wouldn't have failed.

Частые ошибки

  • If I would have known, I would have helped. If I had known, I would have helped.
  • If I had studied, I would passed. If I had studied, I would have passed.
  • If I knew about the party, I would have come. If I had known about the party, I would have come.
  • If she had tried, she would has passed. If she had tried, she would have passed.
Нельзя «if I would have». После if ставим had, после запятой would have.

  3. Bu afsuslanish yoki tanqidmi? Ko'pincha ha: If I had listened ... / If you had told me ...

Fakt va xayol

Real-life use

We use the Third Conditional to talk about regrets, mistakes and what could have happened.

Regrets

"If I had taken the earlier bus, I wouldn't have been late."

Criticism and hindsight

"If you had told me, I would have helped. If he had worn a helmet, he wouldn't have been injured."

Asking about the past

"What would you have done if you had missed the flight?"

IELTS Speaking: talking about a past decision

"If I hadn't started learning English early, I wouldn't have reached this level."

English only

Examples and drill

Positive

If I had studied, I would have passed. If she had called, I would have answered.

Negative

If I hadn't missed the bus, I wouldn't have been late.

Result first

I would have helped if you had asked.

Could and might

If she had tried, she might have passed. If we had had time, we could have visited the museum.

Question

What would you have done if you had lost your keys?

Drill

1. If I ___ (study), I would have passed.
had studied
2. She would have helped if you ___ (ask).
had asked
3. If we ___ (leave) earlier, we wouldn't have missed the train.
had left
4. What ___ you ___ (do) if you had lost your phone?
would ... have done
5. Choose: If I (would have known / had known), I would have helped.
had known
6. "I didn't study, so I failed." → If I ___, I wouldn't have failed.
had studied
7. Correct it: If I would have known, I would have helped.
If I had known, I would have helped.
