Demonstratives

General info

Demonstratives are words that point to things: this, that, these, those. We choose the word by distance (near or far) and by number (one or many).

  • this — one thing, near: This is my phone.
  • that — one thing, far: That is your bag.
  • these — many things, near: These are my books.
  • those — many things, far: Those are your shoes.

We use them for

  • Pointing at things: This is nice. Those are expensive.
  • Introducing people: This is my friend Sara.
  • On the phone: Hello, who is this?
this / that are singular (one). these / those are plural (many). We often use them with here (near) and there (far).

Указательные местоимения указывают на предмет: this, that, these, those. Мы выбираем слово по расстоянию (близко или далеко) и по числу (один или много).

  • this — один предмет, близко: This is my phone.
  • that — один предмет, далеко: That is your bag.
  • these — много предметов, близко: These are my books.
  • those — много предметов, далеко: Those are your shoes.

Когда используем

  • Указываем на предметы: This is nice. Those are expensive.
  • Представляем людей: This is my friend Sara.
  • По телефону: Hello, who is this?
this / that — единственное число (один). these / those — множественное число (много). Часто с here (близко) и there (далеко).

Ko'rsatish olmoshlari narsaga ishora qiladi: this, that, these, those. So'zni masofa (yaqin yoki uzoq) va son (bitta yoki ko'p) bo'yicha tanlaymiz.

  • this — bitta narsa, yaqin: This is my phone.
  • that — bitta narsa, uzoq: That is your bag.
  • these — ko'p narsa, yaqin: These are my books.
  • those — ko'p narsa, uzoq: Those are your shoes.

Qachon ishlatamiz

  • Narsalarga ishora: This is nice. Those are expensive.
  • Odamlarni tanishtirish: This is my friend Sara.
  • Telefonda: Hello, who is this?
this / that — birlik (bitta). these / those — ko'plik (ko'p). Ko'pincha here (yaqin) va there (uzoq) bilan.

Teacher's rule

  1. this + singular, near: This book is good.
  2. these + plural, near: These books are good.
  3. that + singular, far: That car is fast.
  4. those + plural, far: Those cars are fast.
  5. this / that take a singular verb (is, was). these / those take a plural verb (are, were).
  6. They can be pronouns, without a noun: I like this. I want those.
  7. this can introduce a person: This is my brother.
  1. this + единственное, близко: This book is good.
  2. these + множественное, близко: These books are good.
  3. that + единственное, далеко: That car is fast.
  4. those + множественное, далеко: Those cars are fast.
  5. С this / that глагол в единственном числе (is, was). С these / those — во множественном (are, were).
  6. Могут быть местоимениями, без существительного: I like this. I want those.
  7. this может представлять человека: This is my brother.
  1. this + birlik, yaqin: This book is good.
  2. these + ko'plik, yaqin: These books are good.
  3. that + birlik, uzoq: That car is fast.
  4. those + ko'plik, uzoq: Those cars are fast.
  5. this / that bilan fe'l birlikda (is, was). these / those bilan ko'plikda (are, were).
  6. Nomisiz olmosh bo'lib ham keladi: I like this. I want those.
  7. this odamni tanishtirish uchun: This is my brother.

Student explanation

Ask yourself two questions

  1. How many? One → this / that. Many → these / those.
  2. Near or far? Near → this / these. Far → that / those.

Common mistakes

  • These is my book. This is my book.
  • Those is my shoes. Those are my shoes.
  • This are my friends. These are my friends.
  • I like this shoes. I like these shoes.
Sound help: these rhymes with please; those rhymes with nose.

Задай себе два вопроса

  1. Сколько? Один → this / that. Много → these / those.
  2. Близко или далеко? Близко → this / these. Далеко → that / those.

Частые ошибки

  • These is my book. This is my book.
  • Those is my shoes. Those are my shoes.
  • This are my friends. These are my friends.
  • I like this shoes. I like these shoes.
Помощь со звуком: these рифмуется с please; those — с nose.

O'zingizga ikkita savol bering

  1. Nechta? Bitta → this / that. Ko'p → these / those.
  2. Yaqinmi yoki uzoqmi? Yaqin → this / these. Uzoq → that / those.

Ko'p uchraydigan xatolar

  • These is my book. This is my book.
  • Those is my shoes. Those are my shoes.
  • This are my friends. These are my friends.
  • I like this shoes. I like these shoes.
Talaffuz yordami: these please bilan qofiyadosh; those nose bilan.

Real-life use

You use demonstratives all day, every time you point at, hold or see something.

Shopping

"How much is this? And how much are those shoes?"

Showing photos

"This is my family. These are my friends from school."

Introducing people

"This is my colleague, Mr Karimov."

Choosing things

"I like this one, not that one over there."

On the phone

"Hello, who is this?"
