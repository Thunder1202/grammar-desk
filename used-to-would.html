Used to / would

General info

Used to and would talk about past habits and situations that are not true now. They show that something was regular in the past, but it has changed.

We use them for

  • Past habits: We used to visit my grandma every summer.
  • Past states that changed: She used to have long hair. (Now it is short.)
  • Repeated actions in stories: Every morning he would run in the park.

Words that go with them

when I was a child, every day, every summer, always, often, but now.

Russian uses «раньше» + the past (раньше я играл). Uzbek uses -ar edi (o'ynar edim). English uses used to + verb.

Used to и would говорят о прошлых привычках и ситуациях, которых сейчас нет. Они показывают, что раньше что-то происходило регулярно, но изменилось.

Когда используем

  • Прошлые привычки: We used to visit my grandma every summer.
  • Прошлые состояния, которые изменились: She used to have long hair. (Сейчас короткие.)
  • Повторяющиеся действия в рассказах: Every morning he would run in the park.

Слова-подсказки

В русском «раньше» + прошедшее (раньше я играл). В узбекском -ar edi (o'ynar edim). В английском used to + глагол.

Used to va would o'tmishdagi odatlar va hozir yo'q holatlar haqida gapiradi. Ular biror narsa oldin muntazam bo'lganini, lekin o'zgarganini ko'rsatadi.

Qachon ishlatamiz

  • O'tmishdagi odatlar: We used to visit my grandma every summer.
  • O'zgargan o'tmishdagi holatlar: She used to have long hair. (Hozir kalta.)
  • Hikoyada takrorlanuvchi ishlar: Every morning he would run in the park.

  1. used to + base verb = a past habit or state that is no longer true: I used to smoke. (I don't now.)
  2. Negative and question: didn't use to, Did ... use to? There is no -d, because did already shows the past.
  3. would + base verb = repeated past actions only: Every summer we would go to the sea.
  4. Not for states: She used to have a dog. Not: She would have a dog. Same with be, live, like, know.
  5. Not for one-time events: I went to Dubai last year. Not: I used to go to Dubai last year.
  6. Different structure: be used to / get used to + -ing = it is normal for me now: I'm used to getting up early.

And the present?

There is no present form "use to". For present habits use Present Simple, often with usually: I usually walk to work. (not "I use to walk")

Why use would? It sounds like memories and stories: When I was little, my grandmother would tell us stories every night. Start with used to, then continue with would.
  1. used to + основная форма = прошлая привычка или состояние, которого сейчас нет: I used to smoke. (Сейчас не курю.)
  2. Отрицание и вопрос: didn't use to, Did ... use to? Без -d, потому что did уже показывает прошедшее.
  3. would + основная форма = только повторяющиеся прошлые действия: Every summer we would go to the sea.
  4. Не для состояний: She used to have a dog. Не: She would have a dog. То же с be, live, like, know.
  5. Не для разовых событий: I went to Dubai last year. Не: I used to go to Dubai last year.
  6. Другая конструкция: be used to / get used to + -ing = сейчас это для меня нормально: I'm used to getting up early.

А в настоящем?

Формы «use to» в настоящем нет. Для привычек сейчас — Present Simple, часто с usually: I usually walk to work. (а не «I use to walk»)

Зачем would? Оно звучит как воспоминание или рассказ: When I was little, my grandmother would tell us stories every night. Начни с used to, дальше продолжай с would.
  1. used to + asosiy shakl = hozir yo'q o'tmishdagi odat yoki holat: I used to smoke. (Hozir chekmayman.)
  2. Inkor va so'roq: didn't use to, Did ... use to? -d yo'q, chunki did o'tmishni allaqachon ko'rsatadi.
  3. would + asosiy shakl = faqat takrorlanuvchi o'tmish ishlari: Every summer we would go to the sea.
  4. Holatlar uchun emas: She used to have a dog. She would have a dog emas. be, live, like, know bilan ham shunday.
  5. Bir martalik voqea uchun emas: I went to Dubai last year. I used to go to Dubai last year emas.
  6. Boshqa qurilma: be used to / get used to + -ing = hozir menga odatiy: I'm used to getting up early.

Student explanation

Ask yourself three questions

  1. Was it regular in the past and is it different now? Yes → used to.
  2. Is it an action or a state? Action → used to or would. State (have, be, live) → used to only.
  3. Did it happen only once? Yes → Past Simple, not used to.

Used to or be used to?

I used to get up late. (I did it in the past, not now.) / I'm used to getting up early. (It is normal for me now.)

Common mistakes

  • I use to play football. I used to play football.
  • Did you used to live there? Did you use to live there?
  • She would have long hair when she was young. She used to have long hair when she was young.
  • I used to go to Dubai last year. I went to Dubai last year.
After did, always use to without -d: Did you use to, I didn't use to.

In plain words

Use this to talk about your old life: things that were true before but not now. It is like looking through an old photo album.

  • I used to live in Bukhara. I lived there before. Now I don't.
  • He used to smoke. He smoked before, but he stopped.
  • My grandfather would tell me stories. This happened again and again when I was little.

Would is only for repeated actions. For how things were, use used to: "I used to have long hair."

Задай себе три вопроса

  1. Это было регулярно в прошлом, а теперь иначе? Да → used to.
  2. Это действие или состояние? Действие → used to или would. Состояние (have, be, live) → только used to.
  3. Это случилось один раз? Да → Past Simple, не used to.

Used to или be used to?

I used to get up late. (Делал в прошлом, сейчас нет.) / I'm used to getting up early. (Сейчас для меня это нормально.)

Частые ошибки

  • I use to play football. I used to play football.
  • Did you used to live there? Did you use to live there?
  • She would have long hair when she was young. She used to have long hair when she was young.
  • I used to go to Dubai last year. I went to Dubai last year.
После did всегда use to без -d: Did you use to, I didn't use to.

Простыми словами

Используйте это, чтобы говорить о прежней жизни: что было раньше, а теперь нет. Как будто листаете старый фотоальбом.

  • I used to live in Bukhara. Раньше я жил в Бухаре. Теперь нет.
  • He used to smoke. Раньше он курил, но бросил.
  • My grandfather would tell me stories. Дедушка рассказывал мне истории. Так бывало снова и снова в детстве.

Would — только для повторявшихся действий. Для того, как было, используйте used to: "I used to have long hair."

O'zingizga uchta savol bering

  2. Bu ishmi yoki holatmi? Ish → used to yoki would. Holat (have, be, live) → faqat used to.
  3. Bu faqat bir marta bo'ldimi? Ha → Past Simple, used to emas.

Would faqat takrorlangan ishlar uchun. Holat uchun used to ishlating: "I used to have long hair."

Real-life use

We use these forms to talk about childhood, change and memories.

Childhood

"I used to be shy, but now I love speaking."

Comparing then and now

"There used to be a market here. Now it's a park."

Telling a memory

"Every summer we would visit my grandparents. We would pick apples and play outside all day."

IELTS Speaking: childhood

"When I was little, I used to play outside every day, and we would often visit my grandparents on Sundays."
