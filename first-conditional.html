First Conditional

General info

The First Conditional talks about a real, possible situation in the future and its likely result.

We use it for

  • Possible future situations: If it rains, we will stay home.
  • Warnings and advice: If you don't hurry, you will miss the bus.
  • Promises and deals: If you help me, I will buy you lunch.

Words that go with it

if, unless, when, will, won't, might, can.

Russian and Uzbek use the future in both parts (если пойдёт дождь, мы останемся / agar yomg'ir yog'sa, qolamiz). English uses the present simple after if.

First Conditional говорит о реальной, возможной ситуации в будущем и её вероятном результате.

Когда используем

  • Возможные ситуации в будущем: If it rains, we will stay home.
  • Предупреждения и советы: If you don't hurry, you will miss the bus.
  • Обещания и договорённости: If you help me, I will buy you lunch.

Слова-подсказки

if, unless, when, will, won't, might, can.

В русском и узбекском в обеих частях может быть будущее (если пойдёт дождь, мы останемся / agar yomg'ir yog'sa, qolamiz). В английском после if используется present simple.

First Conditional kelajakdagi real, mumkin bo'lgan holat va uning ehtimoliy natijasi haqida gapiradi.

Qachon ishlatamiz

  • Kelajakdagi mumkin holatlar: If it rains, we will stay home.
  • Ogohlantirish va maslahat: If you don't hurry, you will miss the bus.
  • Va'da va kelishuvlar: If you help me, I will buy you lunch.

Yordamchi so'zlar

if, unless, when, will, won't, might, can.

Rus va o'zbek tilida ikkala qismda kelasi zamon bo'lishi mumkin (если пойдёт дождь, мы останемся / agar yomg'ir yog'sa, qolamiz). Inglizchada if dan keyin present simple ishlatiladi.

Teacher's rule

orderWe will stay homeif it rains. (no comma)
  1. Form: If + present simple, will + base verb. Use: a real, possible future situation and its result.
  2. No will in the if-clause: If it rains (not: if it will rain).
  3. Order: if-clause first → comma: If it rains, we will stay home. Result first → no comma: We will stay home if it rains.
  4. Unless = if ... not: Unless you hurry, you will miss the bus. = If you don't hurry, you will miss the bus.
  5. Other results: can, may, might, should or an imperative: If it's sunny, we might go to the beach. If you see Tom, tell him.
  6. If or when? when = it is sure, if = it is possible: When I get home, I'll call you. If I get home early, I'll cook.
  1. Форма: If + present simple, will + основная форма глагола. Употребление: реальная возможная ситуация в будущем и её результат.
  2. Нет will в if-части: If it rains (не: if it will rain).
  3. Порядок: if-часть первой → запятая: If it rains, we will stay home. Результат первым → без запятой: We will stay home if it rains.
  4. Unless = if ... not: Unless you hurry, you will miss the bus. = If you don't hurry, you will miss the bus.
  5. Другие результаты: can, may, might, should или повелительное: If it's sunny, we might go to the beach. If you see Tom, tell him.
  6. If или when? when = точно произойдёт, if = возможно: When I get home, I'll call you. If I get home early, I'll cook.
  1. Shakl: If + present simple, will + asosiy shakl. Qo'llanishi: kelajakdagi real, mumkin holat va uning natijasi.
  2. if qismida will yo'q: If it rains (if it will rain emas).
  3. Tartib: if qismi birinchi → vergul: If it rains, we will stay home. Natija birinchi → vergulsiz: We will stay home if it rains.
  4. Unless = if ... not: Unless you hurry, you will miss the bus. = If you don't hurry, you will miss the bus.
  5. Boshqa natijalar: can, may, might, should yoki buyruq: If it's sunny, we might go to the beach. If you see Tom, tell him.
  6. If yoki when? when = aniq bo'ladi, if = mumkin: When I get home, I'll call you. If I get home early, I'll cook.

Student explanation

Ask yourself three questions

  1. Is the situation real and possible in the future? Yes → First Conditional.
  2. Which part has the condition? The if-part → present simple. The result → will + verb.
  3. Is it sure or only possible? Sure → when. Possible → if.

Common mistakes

  • If it will rain, we will stay home. If it rains, we will stay home.
  • If I would have time, I will help you. If I have time, I will help you.
  • If you don't hurry, you miss the bus. If you don't hurry, you will miss the bus.
  • Unless you don't hurry, you will be late. Unless you hurry, you will be late.
Two parts, two forms: if + present simple, will + verb. Never put will after if.

Задай себе три вопроса

  1. Ситуация реальная и возможная в будущем? Да → First Conditional.
  2. В какой части условие? В части с if → present simple. Результат → will + глагол.
  3. Это точно или только возможно? Точно → when. Возможно → if.

Частые ошибки

  • If it will rain, we will stay home. If it rains, we will stay home.
  • If I would have time, I will help you. If I have time, I will help you.
  • If you don't hurry, you miss the bus. If you don't hurry, you will miss the bus.
  • Unless you don't hurry, you will be late. Unless you hurry, you will be late.
Две части, две формы: if + present simple, will + глагол. Никогда не ставь will после if.

O'zingizga uchta savol bering

  1. Holat real va kelajakda mumkinmi? Ha → First Conditional.
  2. Shart qaysi qismda? if qismida → present simple. Natija → will + fe'l.
  3. Bu aniqmi yoki faqat mumkinmi? Aniq → when. Mumkin → if.

Ko'p uchraydigan xatolar

  • If it will rain, we will stay home. If it rains, we will stay home.
  • If I would have time, I will help you. If I have time, I will help you.
  • If you don't hurry, you miss the bus. If you don't hurry, you will miss the bus.
  • Unless you don't hurry, you will be late. Unless you hurry, you will be late.
Ikki qism, ikki shakl: if + present simple, will + fe'l. if dan keyin hech qachon will qo'ymang.

Real-life use

We use the First Conditional to warn, to promise and to make plans that depend on something.

Warning and advice

"If you don't leave now, you'll miss the train."

Plans

"If the weather is good, we'll go to the park. If it rains, we'll watch a film."

Promises and deals

"If you help me, I'll buy you lunch."

IELTS Speaking: talking about the future

"If I pass the test, I'll apply for a scholarship. If I don't, I'll try again."

English only

Examples and drill

Positive and negative

If it rains, we will stay home. If you don't study, you won't pass.

Result first

I'll help you if you ask me. We will be late if we miss this bus.

Unless

Unless you hurry, you will be late.

Other results

If you see Tom, tell him. If it's sunny, we might go to the beach.

Question

What will you do if you fail the test?

3. I ___ (call) you if I have time.

4. Unless you ___ (study), you won't pass.
study
5. Choose: If I (will see / see) him, I will tell him.
