First Conditional

General info

The First Conditional talks about a real, possible situation in the future and its likely result.

We use it for

  • Possible future situations: If it rains, we will stay home.
  • Warnings and advice: If you don't hurry, you will miss the bus.
  • Promises and deals: If you help me, I will buy you lunch.

Words that go with it

if, unless, when, will, won't, might, can.

Russian and Uzbek use the future in both parts (если пойдёт дождь, мы останемся / agar yomg'ir yog'sa, qolamiz). English uses the present simple after if.

First Conditional говорит о реальной, возможной ситуации в будущем и её вероятном результате.

Когда используем

  • Возможные ситуации в будущем: If it rains, we will stay home.
  • Предупреждения и советы: If you don't hurry, you will miss the bus.
  • Обещания и договорённости: If you help me, I will buy you lunch.

Слова-подсказки

if, unless, when, will, won't, might, can.

В русском и узбекском в обеих частях может быть будущее (если пойдёт дождь, мы останемся / agar yomg'ir yog'sa, qolamiz). В английском после if используется present simple.

First Conditional kelajakdagi real, mumkin bo'lgan holat va uning ehtimoliy natijasi haqida gapiradi.

Qachon ishlatamiz

  • Kelajakdagi mumkin holatlar: If it rains, we will stay home.
  • Ogohlantirish va maslahat: If you don't hurry, you will miss the bus.
  • Va'da va kelishuvlar: If you help me, I will buy you lunch.

Yordamchi so'zlar

if, unless, when, will, won't, might, can.

Rus va o'zbek tilida ikkala qismda kelasi zamon bo'lishi mumkin (если пойдёт дождь, мы останемся / agar yomg'ir yog'sa, qolamiz). Inglizchada if dan keyin present simple ishlatiladi.

Teacher's rule

if-clauseresult clause
+If it rains,we will stay home.
−If you don't hurry,you will miss the bus.
?What will you do if you fail the test?
orderWe will stay homeif it rains. (no comma)
  1. Form: If + present simple, will + base verb. Use: a real, possible future situation and its result.
  2. No will in the if-clause: If it rains (not: if it will rain).
  3. Order: if-clause first → comma: If it rains, we will stay home. Result first → no comma: We will stay home if it rains.
  4. Unless = if ... not: Unless you hurry, you will miss the bus. = If you don't hurry, you will miss the bus.
  5. Other results: can, may, might, should or an imperative: If it's sunny, we might go to the beach. If you see Tom, tell him.
  6. If or when? when = it is sure, if = it is possible: When I get home, I'll call you. If I get home early, I'll cook.

Why present simple after if?

The word if already tells us we are talking about the future, so English does not need will a second time. The same is true after when, before, after, as soon as and until: When I arrive, I'll call you.

Negatives

Either part can be negative, or both. In the if-part use don't / doesn't + verb. In the result use won't (= will not) + verb.

Negative inExample
the if-partIf you don't hurry, you'll be late.
the resultIf it rains, we won't go out.
both partsIf she doesn't call, I won't wait.

Questions

Make the question in the result part, with will: Will + subject + verb ... if ...? The if-part stays a normal statement.

TypeExample
Yes / noWill you come if I invite you? — Yes, I will. / No, I won't.
Question wordWhat will you do if you miss the bus?
If-part firstIf it rains tomorrow, will the match be cancelled?
Don't make the if-part a question: not "If does it rain…", but "If it rains, will we…?"

Zero, first or second conditional?

All three use if, but they show a different chance.

TypeExampleMeaning
Zero: if + present, presentIf you heat ice, it melts.always true, a fact
First: if + present, willIf it rains tomorrow, I'll take a taxi.a real chance in the future
Second: if + past, wouldIf I won the lottery, I'd buy a house.imagined or very unlikely
Ask yourself: is it always true? → zero. Could it really happen? → first. Is it a dream or not real? → second.
  1. Форма: If + present simple, will + основная форма глагола. Употребление: реальная возможная ситуация в будущем и её результат.
  2. Нет will в if-части: If it rains (не: if it will rain).
  3. Порядок: if-часть первой → запятая: If it rains, we will stay home. Результат первым → без запятой: We will stay home if it rains.
  4. Unless = if ... not: Unless you hurry, you will miss the bus. = If you don't hurry, you will miss the bus.
  5. Другие результаты: can, may, might, should или повелительное: If it's sunny, we might go to the beach. If you see Tom, tell him.
  6. If или when? when = точно произойдёт, if = возможно: When I get home, I'll call you. If I get home early, I'll cook.

Почему после if present simple?

Слово if уже показывает, что речь о будущем, поэтому второй раз will не нужен. В русском после «если» стоит будущее (если пойдёт дождь), а в английском — настоящее (if it rains). То же после when, before, after, as soon as, until: When I arrive, I'll call you.

Отрицание

Отрицательной может быть любая часть или обе. В части с if — don't / doesn't + глагол. В результате — won't (= will not) + глагол.

Где отрицаниеПример
в части с ifIf you don't hurry, you'll be late.
в результатеIf it rains, we won't go out.
в обеих частяхIf she doesn't call, I won't wait.

Вопрос

Вопрос строим в части-результате, с will: Will + подлежащее + глагол ... if ...? Часть с if остаётся обычным утверждением.

ТипПример
Да / нетWill you come if I invite you? — Yes, I will. / No, I won't.
С вопросительным словомWhat will you do if you miss the bus?
Часть с if первойIf it rains tomorrow, will the match be cancelled?
Не делай вопрос из части с if: не «If does it rain…», а «If it rains, will we…?»

Zero, First или Second Conditional?

Во всех трёх есть if, но шанс разный.

ТипПримерСмысл
Zero: if + present, presentIf you heat ice, it melts.верно всегда, факт
First: if + present, willIf it rains tomorrow, I'll take a taxi.реальный шанс в будущем
Second: if + past, wouldIf I won the lottery, I'd buy a house.воображаемое или очень маловероятное
Спроси себя: это верно всегда? → zero. Это правда может случиться? → first. Это мечта или нереально? → second.
  1. Shakl: If + present simple, will + asosiy shakl. Qo'llanishi: kelajakdagi real, mumkin holat va uning natijasi.
  2. if qismida will yo'q: If it rains (if it will rain emas).
  3. Tartib: if qismi birinchi → vergul: If it rains, we will stay home. Natija birinchi → vergulsiz: We will stay home if it rains.
  4. Unless = if ... not: Unless you hurry, you will miss the bus. = If you don't hurry, you will miss the bus.
  5. Boshqa natijalar: can, may, might, should yoki buyruq: If it's sunny, we might go to the beach. If you see Tom, tell him.
  6. If yoki when? when = aniq bo'ladi, if = mumkin: When I get home, I'll call you. If I get home early, I'll cook.

Nega if dan keyin present simple?

if so'zining o'zi kelajak haqida gapirayotganimizni ko'rsatadi, shuning uchun will ikkinchi marta kerak emas. O'zbek tilida ham shunday: "yomg'ir yog'sa" deymiz, kelasi zamon qo'shimchasi qo'shilmaydi. when, before, after, as soon as, until dan keyin ham shunday: When I arrive, I'll call you.

Student explanation

Ask yourself three questions

  1. Is the situation real and possible in the future? Yes → First Conditional.
  2. Which part has the condition? The if-part → present simple. The result → will + verb.
  3. Is it sure or only possible? Sure → when. Possible → if.

Common mistakes

  • If it will rain, we will stay home. If it rains, we will stay home.
  • If I would have time, I will help you. If I have time, I will help you.
  • If you don't hurry, you miss the bus. If you don't hurry, you will miss the bus.
  • Unless you don't hurry, you will be late. Unless you hurry, you will be late.
Two parts, two forms: if + present simple, will + verb. Never put will after if.

In plain words

This is about a real chance in the future. It is like a fork in the road: if this happens, that will follow. It may or may not happen, but it is possible.

  • If it rains, we will stay at home. Rain is possible. Staying home is the result.
  • If you study, you will pass. Studying is your choice. Passing follows.
  • I'll call you if I have time. The order can change, and the meaning stays the same.

After if, do not use will. Say "if it rains", not "if it will rain".

Задай себе три вопроса

  1. Ситуация реальная и возможная в будущем? Да → First Conditional.
  2. В какой части условие? В части с if → present simple. Результат → will + глагол.
  3. Это точно или только возможно? Точно → when. Возможно → if.

Частые ошибки

  • If it will rain, we will stay home. If it rains, we will stay home.
  • If I would have time, I will help you. If I have time, I will help you.
  • If you don't hurry, you miss the bus. If you don't hurry, you will miss the bus.
  • Unless you don't hurry, you will be late. Unless you hurry, you will be late.
Две части, две формы: if + present simple, will + глагол. Никогда не ставь will после if.

Простыми словами

Это о реальном шансе в будущем. Как развилка на дороге: если случится это, то будет то. Может случиться, может нет, но это возможно.

  • If it rains, we will stay at home. Если пойдёт дождь, мы останемся дома. Дождь возможен, дом — результат.
  • If you study, you will pass. Если будешь учиться, сдашь. Учёба — твой выбор, результат следует за ним.
  • I'll call you if I have time. Я позвоню, если будет время. Порядок можно менять, смысл тот же.

После if не ставим will. Правильно "if it rains", а не "if it will rain".

O'zingizga uchta savol bering

  1. Holat real va kelajakda mumkinmi? Ha → First Conditional.
  2. Shart qaysi qismda? if qismida → present simple. Natija → will + fe'l.
  3. Bu aniqmi yoki faqat mumkinmi? Aniq → when. Mumkin → if.

Ko'p uchraydigan xatolar

  • If it will rain, we will stay home. If it rains, we will stay home.
  • If I would have time, I will help you. If I have time, I will help you.
  • If you don't hurry, you miss the bus. If you don't hurry, you will miss the bus.
  • Unless you don't hurry, you will be late. Unless you hurry, you will be late.
Ikki qism, ikki shakl: if + present simple, will + fe'l. if dan keyin hech qachon will qo'ymang.

Oddiy so'zlar bilan

Bu kelajakdagi real imkoniyat haqida. Yo'l ayrilishiga o'xshaydi: bu bo'lsa, u keladi. Bo'lishi ham, bo'lmasligi ham mumkin, lekin imkoni bor.

  • If it rains, we will stay at home. Yomg'ir yog'sa, uyda qolamiz. Yomg'ir bo'lishi mumkin, uyda qolish natija.
  • If you study, you will pass. O'qisang, o'tasan. O'qish sening tanloving, natija undan keladi.
  • I'll call you if I have time. Vaqtim bo'lsa, qo'ng'iroq qilaman. Tartib o'zgarishi mumkin, ma'no o'sha.

If dan keyin will ishlatilmaydi. "if it rains" to'g'ri, "if it will rain" emas.

Real-life use

We use the First Conditional to warn, to promise and to make plans that depend on something.

Warning and advice

"If you don't leave now, you'll miss the train."

Plans

"If the weather is good, we'll go to the park. If it rains, we'll watch a film."

Promises and deals

"If you help me, I'll buy you lunch."

IELTS Speaking: talking about the future

"If I pass the test, I'll apply for a scholarship. If I don't, I'll try again."

English only

Examples and drill

Positive and negative

If it rains, we will stay home. If you don't study, you won't pass.

Result first

I'll help you if you ask me. We will be late if we miss this bus.

Unless

Unless you hurry, you will be late.

Other results

If you see Tom, tell him. If it's sunny, we might go to the beach.

Question

What will you do if you fail the test?

Drill

1. If it ___ (rain), we will stay home.
rains
2. If you ___ (not hurry), you will miss the bus.
don't hurry
3. I ___ (call) you if I have time.
will call
4. Unless you ___ (study), you won't pass.
study
5. Choose: If I (will see / see) him, I will tell him.
see
6. Choose: I'll call you (if / when) I arrive tonight. I'm sure I will arrive.
when
7. Correct it: If I would have time, I will help you.
If I have time, I will help you.
8. If he ___ (not / find) a job, he ___ (move) to another city.
doesn't find, will move
9. They ___ (be) tired if they ___ (walk) all the way.
will be, walk

Make it negative

10. If you study, you will pass. (make both parts negative)
If you don't study, you won't pass.
11. If it is sunny, we will go to the beach. (make the result negative)
If it is sunny, we won't go to the beach.

Make a question

12. (what / you / do) if the shop is closed?
What will you do if the shop is closed?
13. (she / be) angry if we are late?
Will she be angry if we are late?
14. Will you help me if I ask? (yes, short answer)
Yes, I will.

If or unless?

15. Rewrite with unless: If you don't take a coat, you'll be cold.
Unless you take a coat, you'll be cold.
16. Rewrite with if: Unless it stops raining, we won't play.
If it doesn't stop raining, we won't play.

Zero, first or second?

17. If you ___ (mix) red and white, you get pink.
mix (zero: always true)
18. If I ___ (see) Anna tomorrow, I'll give her the book.
see (first: a real chance)
19. If I ___ (be) a bird, I would fly to Paris.
were (second: not real)

Find the mistake

20. If she will call, I'll tell you.
If she calls, I'll tell you.
21. We will go out if it won't rain.
We will go out if it doesn't rain.
22. When I will finish, I'll call you.
When I finish, I'll call you.
