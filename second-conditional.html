Second Conditional

General info

The Second Conditional talks about an imaginary or unlikely situation now or in the future, and its result.

We use it for

  • Imaginary situations: If I had a car, I would drive to work. (I don't have a car.)
  • Unlikely future: If I won the lottery, I would travel the world.
  • Advice: If I were you, I would talk to him.

Words that go with it

if, would, wouldn't, could, might, if I were you.

Russian and Uzbek use «бы» / -sa ... edi (если бы у меня была машина / agar mashinam bo'lsa edi). English uses the past simple after if and would in the result.

Second Conditional говорит о воображаемой или маловероятной ситуации сейчас или в будущем и её результате.

Когда используем

  • Воображаемые ситуации: If I had a car, I would drive to work. (У меня нет машины.)
  • Маловероятное будущее: If I won the lottery, I would travel the world.
  • Совет: If I were you, I would talk to him.

Слова-подсказки

if, would, wouldn't, could, might, if I were you.

В русском есть «бы», в узбекском -sa ... edi (если бы у меня была машина / agar mashinam bo'lsa edi). В английском после if past simple, в результате would.

Second Conditional hozirgi yoki kelajakdagi xayoliy yoki ehtimoli kam holat va uning natijasi haqida gapiradi.

Qachon ishlatamiz

  • Xayoliy holatlar: If I had a car, I would drive to work. (Mashinam yo'q.)
  • Ehtimoli kam kelajak: If I won the lottery, I would travel the world.
  • Maslahat: If I were you, I would talk to him.

Yordamchi so'zlar

  1. Form: If + past simple, would + base verb. Use: an imaginary or unlikely situation now or in the future.
  2. The past form is not past time. If I had money = I don't have money now.
  3. No would in the if-clause: If I had (not: if I would have).
  4. To be: use were for all persons in the if-clause: If I were you, ... If he were here, ... (was is heard in informal speech). If I were you = advice.
  5. Order and comma are the same as in the First Conditional. You can use could or might instead of would: If I had time, I could learn French.
  6. First or Second? Real and possible → First: If it rains, we will stay. Imaginary or unlikely → Second: If I won the lottery, I would travel.

  3. Нет would в if-части: If I had (не: if I would have).
  4. To be: were для всех лиц в if-части: If I were you, ... If he were here, ... (в разговорной речи слышно was). If I were you = совет.

Student explanation

Ask yourself three questions

  1. Is it real and possible, or imaginary and unlikely? Real → First Conditional. Imaginary → Second Conditional.
  2. Which part has the condition? The if-part → past simple. The result → would + verb.
  3. Am I giving advice? Yes → If I were you, I would ...

Common mistakes

  • If I would have money, I would buy a car. If I had money, I would buy a car.
  • If I were you, I will take the job. If I were you, I would take the job.
  • If he would study, he would pass. If he studied, he would pass.
  • If I have a million dollars, I would travel. If I had a million dollars, I would travel.
Imaginary = past simple after if, would in the result. Never put would after if.

Задай себе три вопроса

  1. Реально и возможно или воображаемо и маловероятно? Реально → First Conditional. Воображаемо → Second Conditional.
  2. В какой части условие? В части с if → past simple. Результат → would + глагол.
  3. Я даю совет? Да → If I were you, I would ...

Частые ошибки

  • If I would have money, I would buy a car. If I had money, I would buy a car.
  • If I were you, I will take the job. If I were you, I would take the job.
  • If he would study, he would pass. If he studied, he would pass.
  • If I have a million dollars, I would travel. If I had a million dollars, I would travel.
Воображаемое = past simple после if, would в результате. Никогда не ставь would после if.

Real-life use

We use the Second Conditional to give advice, to dream and to ask "what if?" questions.

Giving advice

"If I were you, I'd talk to him. I wouldn't wait."

Dreams

"If I had more time, I'd learn to play the guitar."

What if?

"What would you do if you lost your job?"

IELTS Speaking: imagining a change

"If I could change one thing about my city, I would build more parks. People would be happier, and the air would be cleaner."

Examples and drill

Imaginary now

If I had a car, I would drive to work. If she lived here, we would see her every day.

Unlikely future

If I won the lottery, I would travel the world.

Advice with were

If I were you, I would call him. If I were you, I wouldn't wait.

Could and might

If I had time, I could learn French. If he tried, he might pass.

Question

What would you do if you lost your keys?
